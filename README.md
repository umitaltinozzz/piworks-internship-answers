## Overview

Solutions to the P.I. Works internship application tasks, one folder per question. Each folder contains the original problem statement (`problem.md`) and my answer — SQL, code, a UI specification, an estimation methodology or a product analysis.

## Project Status

Completed application submission, archived.

## Features

- Q3 — SQL queries over an employee payments schema
- Q4 — Three-digit primes starting with 5, in Python and C with pseudocode
- Q5 — User management UI specification
- Q6 — Fermi estimation of mobile base stations in Istanbul, with methodology and sources
- Q7 — WhatsApp product-management feature analysis

## Tech Stack

| Layer | Technology |
|---|---|
| SQL | Schema + queries |
| Code | Python, C |
| Analysis | Markdown |

## Getting Started

Each question is self-contained. For example:

```bash
python 4-3-digit-primes-starting-with-5/primes.py
gcc 4-3-digit-primes-starting-with-5/primes.c -o primes && ./primes
```
